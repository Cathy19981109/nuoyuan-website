# 诺元智合 - 管理后台

Vue 3 + Vite 构建的可视化管理后台，对接 `backend` 项目的 `/api/admin` 接口。

## 快速开始

```bash
cd Auth
npm install
npm run dev
```

访问：**http://localhost:5174**

默认账号：`admin` / `123456`

**注意：** 需先启动后端服务（`backend` 目录）。

## 功能模块

| 模块 | 路径 | 功能 |
|------|------|------|
| 控制台 | `/dashboard` | 数据概览与快捷入口 |
| 导航管理 | `/nav` | 增删改导航菜单 |
| 页面管理 | `/pages` | 编辑各子页面富文本内容 |
| 产品分类 | `/product-categories` | 管理产品分类树 |
| 产品管理 | `/products` | 管理产品/服务 |
| 新闻分类 | `/news-categories` | 管理新闻分类 |
| 新闻管理 | `/news` | 发布/编辑新闻 |
| 应用领域 | `/applications` | 管理应用领域 |
| 询价管理 | `/inquiries` | 查看和处理询价 |
| 系统配置 | `/config` | 网站信息、SMTP 邮件配置 |

## 运营后台使用说明（v5）

- 左侧菜单
  - 初始只显示一级菜单，点击后展开二级菜单，再点可收起
  - 二级菜单有小圆点，字号更小，方便区分层级
  - 当前页面菜单为蓝底白字，其他菜单为浅灰色
- 页面编辑（`/page-editor`）
  - 顶部横向 Tab 显示全部前台页面（可拖拽排序）
  - 支持新增页面、编辑页面、删除页面
  - 每个页面分两个区域：
    - 导航信息：导航名称、英文名、父级导航、跳转方式、横幅图上传、状态
    - 导航内容：模块列表（拖拽排序、编辑、删除入回收站）
- 模块模板（精简5套）
  - 全屏宽幅单图
  - 图文分栏模块（图内/图上/图下/图左/图右）
  - 多图轮播模块（逐张上传、可增删上传位、可拖拽排序）
  - 单视频模块（mp4，<=10MB）
  - 图文跳转按钮模块（外链或绑定产品5位编号）
- 列表分页（产品/资讯/询价）
  - 每页可选 10/20/50 条
  - 支持首页、上一页、下一页、末页、页码跳转
- 询价高级检索（`/inquiries`）
  - 可同时按：联系人姓名、联系电话、邮箱、公司、咨询产品名称/ID 检索
  - 点击“清空”恢复全量记录

## 上传规范（后台编辑时请遵守）

- Logo：1:1，推荐200x200，png/jpg/webp，<=500KB
- 导航下拉横幅：16:6，推荐1920x720，png/jpg/webp，<=1MB
- 页脚二维码：1:1，推荐300x300，透明png，<=300KB
- 其他模块图片：各模块弹窗有单独尺寸提示，请按提示上传

## 三端启动

```bash
# 终端1 - 后端
cd backend && npm run dev

# 终端2 - 官网前台
cd frontend && npm run dev    # http://localhost:5173

# 终端3 - 管理后台
cd Auth && npm run dev        # http://localhost:5174
```

## 构建部署

```bash
npm run build
npm run preview
```

生产环境需配置 Nginx 将 `/api` 反向代理到后端服务。
