# 诺元智合官网上线 — 客户操作指引（阿里云）

> 适用对象：网站归属公司（客户）  
> 技术部署可由服务方协助完成；**云账号、域名、备案须使用贵司主体**，请勿使用个人或服务方账号长期托管官网。

---

## 一、为什么需要贵司亲自操作？

域名实名、云服务器、ICP 备案均须绑定**公司营业执照主体**。账号与资产在贵司名下，便于：

- 合规备案与后续年审  
- 费用、发票归属清晰  
- 日后更换服务方时网站仍归属贵司  

服务方可协助填写资料、部署网站；**法人核验、短信验证等环节须贵司配合完成**。

## 六、操作步骤总览

1. 注册阿里云并完成**企业实名**  
2. 注册域名并完成**域名实名**  
3. 购买**国内**云服务器  
4. 提交 **ICP 备案**（等待审核）  
5. 备案通过后，通知服务方绑定域名并正式开放网站  

预计：采购当天可完成；备案审核通常需数个工作日至数周（以管局为准）。

## 七、分步操作说明

### 步骤 1：注册阿里云（企业账号）

1. 打开 [https://www.aliyun.com](https://www.aliyun.com)  
2. 注册账号，选择**企业实名认证**  
3. 按提示上传营业执照、法人信息并完成核验  
4. （推荐）在控制台为服务方开通**子账号/协作者**，仅授予运维所需权限，勿交出主账号密码  

完成后请告知服务方：**阿里云登录账号（主账号可打码）、是否已开通协作权限**。

---

### 步骤 2：注册域名

1. 进入阿里云「域名」产品页  
2. 查询并注册官网域名（如 `yourbrand.com`）  
3. 完成**域名实名认证**（与企业主体一致）  
4. 记录已注册的完整域名，发给服务方  

说明：未备案前，域名可能暂时无法在中国大陆稳定访问，属正常现象。

---

### 步骤 3：购买云服务器

1. 推荐优先看「**轻量应用服务器**」或「云服务器 ECS」新人套餐  
2. 关键注意：  
   - **地域**：选择中国内地（如公司所在省份或就近地域），便于备案  
   - **系统镜像**：Ubuntu 22.04（或服务方指定版本）  
   - **带宽**：官网起步常见 3Mbps～5Mbps，可按访问量再升配  
3. 购买完成后，在控制台放行安全组/防火墙：**80、443**（以及 SSH 22，仅限运维需要）  
4. 将以下信息发给服务方（可通过安全渠道）：  
   - 服务器公网 IP  
   - 登录方式（密钥或临时密码，首次登录后请修改）  
   - 地域与配置截图  

费用建议由贵司账户支付，便于开具发票、资产归属清晰。

---

### 步骤 4：提交 ICP 备案

1. 登录阿里云控制台 → 搜索「**ICP 备案**」  
2. 按向导填写：  
   - 主体：公司营业执照信息  
   - 网站：网站名称、域名、服务内容（企业官网）  
   - 负责人：按要求上传证件并完成核验（人脸/短信）  
3. 网站服务内容如实填写「企事业单位网站」等（以页面选项为准）  
4. 提交后等待初审、管局审核；留意短信/邮件，及时补正材料  

备案期间服务方可同步准备部署；**正式用域名对外开放，须等备案通过**。

---

### 步骤 5：备案通过后（与服务方配合）

请通知服务方并确认：

1. 域名已解析到服务器  
2. 已配置 HTTPS 证书  
3. 管理后台、前台均可正常打开  
4. 在管理后台按第三节路径，将「**对外开放**」设为开放并保存  

贵司可用无痕浏览器访问正式域名做最终验收。

## 十、常见问题

**Q：可以让服务方用他们的账号先上线吗？**  
不建议。主体不一致会导致备案、过户、发票和后续维护风险。

**Q：备案要多久？**  
各地管局不同，常见为数个工作日至数周，以阿里云备案进度与短信通知为准。

**Q：备案没过之前，外面能打开网站吗？**  
国内用域名正式访问通常受限。关闭状态下访客看到「即将上线」；内部可用预览链接验收。

**Q：个人认证能不能备案企业官网？**  
企业官网应使用**企业主体**账号与材料备案。
