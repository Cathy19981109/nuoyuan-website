## 为什么本地改了线上不变？

1. **代码**：Vercel / Railway 只跟 GitHub 的 `main` 分支。本地未 commit / 未 push 到 `main`，线上不会更新。
2. **内容**：产品、页面模块、SEO、配置在 **MySQL** 里。本地库和 Railway 库是两套，改后台只写本地库时，海外站看不到。
3. **图片**：上传文件在 `backend/uploads/`。Railway 若无持久卷，需把图片一并同步进仓库或重新上传。

## 更新步骤（每次一起更新）

### A. 推送代码（自动触发重新部署）

```bash
cd /Users/liuluyao/Desktop/Demo
git checkout main
git merge cursor/section-nav-catalog-pages   # 或当前开发分支
git push origin main
```

然后等待：

- Railway 后端重新 Deploy（约 1–3 分钟）
- Vercel 前台 / 后台重新 Build（约 1–3 分钟）

### B. 同步数据库内容（Navicat）

1. 工具 → **数据传输**
2. 源：本地 `cathy` → `nuoyuan_website`
3. 目标：`railway` → `railway`
4. 勾选表结构 + 数据，覆盖目标
5. 传输完成后，在 Railway 库执行下面 SQL，**保持海外临时站对外开放**（本地可继续关着做阿里云准备）：

```sql
INSERT INTO nuoyuan_config (config_key, config_value, name, description, sort)
VALUES ('site_public_open', '1', '网站对外开放', '海外临时站保持开放', 0)
ON DUPLICATE KEY UPDATE config_value = '1';
```

若 `config_key` 无唯一索引，改用：

```sql
UPDATE nuoyuan_config SET config_value = '1' WHERE config_key = 'site_public_open';
-- 若影响行数为 0，再插入一行
```

### C. 同步上传图片（可选但推荐）

把本地 `backend/uploads/images/` 新图片随代码 push，或在海外管理后台重新上传。

### D. 验证

- Health：https://nuoyuan-website-production.up.railway.app/health
- 官网首页：https://nuoyuan-frontend.vercel.app （应能看到最新内容，不是「即将上线」）
- 强制刷新：`Cmd+Shift+R`

## 注意

- 本地「网站开放」设为关闭，只影响本地 / 将来阿里云；同步库后务必在 Railway 把 `site_public_open` 设为 `1`。
- 国内访问 Vercel / Railway 可能不稳定，临时站主要用于演示。
